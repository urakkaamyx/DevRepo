# Endo — Complete Architecture & Build Package

**Status:** Stable Architecture Baseline

Endo is the complete managed development environment and orchestration system.

Projects are independent repositories managed by Endo.
Tools extend Endo's reach.
Endo AI is a separate, provider-neutral natural-language interface over the Endo command engine.

This package is intended as a handoff to another AI/engineering system for implementation.
